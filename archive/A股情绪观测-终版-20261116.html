五、可验证性骨架：stockproof（防过拟合）

README 已核实属实：taoqizhang55-code/marketmood 已改名 stockproof（MIT，2026-11-06 更新，1 star）。它的价值不在"抓情绪"，而在把情绪信号推进到"历史上是否真的有预测力"：

  • LLM 读新闻/财报/公告并附原文引用；每个信号在十年 point-in-time 数据上回测，无未来函数（EPS 按首次披露、按真实公告日、消息后入场）。
  • 最近 2 年默认锁定，需确认一次才解锁；每多试一个变体就提高显著性门槛——直接针对"反复调参挖出假信号"。
  • 自带案例：某预测器在 2010–24 有效，但在锁定的 2024-11→2026 失效，应用明确标注"历史上通过、近两年失败"。

用法：把 vibe-astock 或自建指标产生的情绪信号，写成小 spec 丢进 lab 做 point-in-time 检验，先过锁定样本外再看全样本。这一步是"效果优先"和"盲目堆指标"的分界线。
